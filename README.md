# CUL-CYB 371 - Assignment Two

## Student Dataset

This project contains a fictional dataset of 15 students. It was created with Python and saved as a CSV file.

## Dataset fields

- `Student_ID`: A unique fictional identifier for each student.
- `Department`: The student's academic department.
- `Level`: The student's current academic level.
- `Attendance_Percentage`: The student's attendance, expressed as a percentage.
- `Average_Examination_Score`: The student's average examination score, expressed as a percentage.

## Files

- `create_dataset.py`: Python program that creates the dataset.
- `student_dataset.csv`: The generated dataset.
- `README.md`: Project description and instructions.

## How to run

1. Install Python 3 if it is not already installed.
2. Open a terminal in this project folder.
3. Run:

   ```bash
   python3 create_dataset.py
   ```

4. The program creates `student_dataset.csv` in the same folder.

## Note

All student records and scores in this project are fictional and are provided for educational purposes only.
